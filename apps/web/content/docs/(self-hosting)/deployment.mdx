---
title: Deploy the server
description: Run the control plane and relay as independent services.
icon: Server
---

The server-side Go commands have separate responsibilities and can be
deployed independently:

- `cmd/server` runs the control-plane API.
- `cmd/tunnel` runs the public relay and data plane.
- `cmd/cron` runs scheduled maintenance and aggregation jobs.
- `cmd/check` performs internal health and edge verification.
- `cmd/cli` is a workstation binary, not a server deployment.

The API and relay share PostgreSQL and Redis according to their environment
configuration. The CLI connects to the API over HTTPS and opens its live
session with the relay over WebSocket.

Build the server containers from the repository's command-specific Dockerfiles
under `docker/`.
