---
title: Vite plugin
description: Open a development tunnel automatically with Vite.
icon: SiVite
---

Install the plugin:

```sh
npm install -D @codedock-tunnel/vite-plugin
```

Register it in `vite.config.ts`:

```ts
import { defineConfig } from 'vite';
import { codedockTunnel } from '@codedock-tunnel/vite-plugin';

export default defineConfig({
  plugins: [
    codedockTunnel({
      relayUrl: process.env.CODEDOCK_TUNNEL_RELAY_URL!,
      agentToken: process.env.CODEDOCK_TUNNEL_AGENT_TOKEN!,
      subdomain: 'my-preview',
    }),
  ],
});
```

The plugin only runs during Vite development. It uses the Vite server port by
default, closes the connection when the dev server shuts down, and supports
the shared `password` option for protected previews.
