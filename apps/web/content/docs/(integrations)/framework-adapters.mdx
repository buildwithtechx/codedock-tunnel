---
title: Framework adapters
description: Add tunnel lifecycle to React, Vite, Next.js, NestJS, or Express.
icon: PanelsTopLeft
---

Framework packages are intentionally thin. They delegate authentication,
tunnel state, reconnect behavior, and protocol work to `@codedock-tunnel/sdk-ts`.

This keeps the public behavior consistent across frameworks and lets an
application move between adapters without changing its tunnel model.

Use the adapter matching your runtime, and use `sdk-ts` directly for custom
frameworks or server processes.
